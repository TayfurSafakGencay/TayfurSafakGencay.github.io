First Person Shooter

I wanted to create a highly detailed and enjoyable game entirely built with my own systems and code to both enhance my skills and expand my portfolio. I focused deeply on many intricate details and tackled a variety of technical challenges. Here's an overview of the systems and features I developed for this project:

FPS Gameplay Mechanics: Smooth shooting mechanics, including camera shake, weapon recoil, and animations like Reload and Run. Additionally, features like damage scaling by distance and scope functionality are integrated for a polished experience.

Weapon Systems: Implemented a Scriptable Object-based weapon system with customizable settings such as bullet trails, a spray system (adjustable by texture or Vector3 settings), and sound variations when ammo is low.

Zombie AI and Interactions: Developed an optimized spawn system using Object Pooling, where zombies only spawn when the player is nearby. Zombies are equipped with a ragdoll system for realistic limb detachment, and they react based on player sounds (footsteps, weapon noise). Damage calculation is based on the specific body part hit.

Environmental Features: A dynamic Day & Night system with immersive Post Process effects. Added realistic soundscapes like flowing water that adjust based on the player's position and surface-dependent footstep sounds.

Survival and Immersion Mechanics: Players experience fatigue from running, low-health heartbeat sounds, and a pill-taking animation for recovery. Zombies emit random sounds to enhance the atmosphere, and a radar system helps locate remaining zombies.

Game Progression: Once the map is cleared, a helicopter arrives for extraction, signaling the endgame phase. The game also features a functional loot system to gather resources during gameplay.

Inventory System: Includes a basic inventory system for managing collected items, contributing to the player's survival strategy.

Optimizations: Focused heavily on performance with techniques like Addressables for asset management and Object Pooling for efficient enemy spawning.

This project has been a major learning experience, and I've worked on a variety of systems to improve both my technical and creative skills.
